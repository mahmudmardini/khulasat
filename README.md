# خُلاصات

منصّة تحوّل دروس المساجد والمراكز الإسلامية إلى ملخّصات بصرية موثّقة الشواهد، تُنشر بالعربية وبثلاث لغات أخرى.

تدخل المحاضرة رابطَ يوتيوب أو ملفّاً صوتياً أو نصّاً، فيُفرَّغ الكلام وتستخرج النماذج اللغوية محاوره وشواهده ثمّ تكتب الملخّص. **ولا يُنشر شاهدٌ لم يُطابَق.** فكلّ آية تُطابَق حرفاً على المصحف المحلّي، وكلّ حديث على الكتب الستّة وموطّأ مالك، مطابقةً نصّية حتمية لا يشارك فيها نموذج لغوي. وما لم يُطابَق لا يُنشر: إمّا يُحذف من الملخّص، وإمّا تقف المهمّة بحالة `needs_review` حتى يقرّر فيه إنسان. ولا إعداد في المنصّة يتجاوز هذا.

> **Khulasat** turns Islamic lectures into visual, multilingual summaries. Every Qur'anic verse and hadith quoted by the language models is checked against a local corpus by deterministic text matching — no LLM in the verification layer — and nothing unverified is ever published.

## ما يميّز المنصّة

- **طبقة تحقّق بلا نموذج لغوي.** تُطبَّع النصوص العربية أوّلاً: التشكيل، وصور الهمزة، والرسم العثماني مقابل الإملائي. ثمّ تُطابَق الآية على المصحف (6236 آية، حفص عن عاصم) والحديثُ على الكتب الستّة والموطّأ. التنفيذ في `app/Services/Verification/` و`app/Support/Hadith/`.
- **عيّنة شواهد مدسوسة معيارُ قبول.** يحوي `fixtures/evidence-fixtures.json` إحدى وعشرين حالة، منها آية بُدّلت فيها كلمة، وآية رُكّبت من سورتين، وحديث صحيح حُرّف لفظه، وأحاديث مشهورة على الألسنة لا أصل لها. وتفحص الـCI في كلّ تغيير أنّ كلّ حالة تنتهي إلى حكمها المنصوص.
- **بوّابة نماذج مستقلّة عن المزوّد.** لكلّ مرحلة من المراحل الستّ نموذج أساسيّ وبديل (Anthropic وOpenAI وGoogle)، وتُحسب كلفة كلّ نداء. ولا يُستدعى نموذج قبل فحص حصّة الجهة وسقف الإنفاق اليومي والشهري.
- **نشرٌ بأربع لغات.** العربية والإنجليزية والتركية والروسية. وتأتي الآية في الصفحة المترجَمة بترجمة معتمدة لا بترجمة النموذج.
- **منصّة متعدّدة الجهات.** لكلّ جهة هويتها البصرية وفريقها وحصّتها ونطاقها. وتتيح لوحة المشرف متابعة الكلفة والنماذج والشكاوى.

## المرجعية والمصادر

نعتمد مصادر خارجية موثوقة ونذكرها كلّها، كما أجازت لجنة التحكيم. والتفصيل بنداً بنداً في القسم الأوّل من [SOURCES.md](SOURCES.md).

| | المصدر |
|---|---|
| **القرآن** | نصّ المصحف برواية حفص، من Quran Foundation. ولا تُنشر آيةٌ إلّا بلفظه |
| **الحديث** | الصحيحان والسنن الأربع والموطّأ، بأحكام المحدّثين منسوبةً إليهم. **ولا يُنشر حديثٌ بلا حكم**، ولكلّ حديثٍ رابطُ بحثٍ في الدرر السنية |
| **ترجمة معاني الآيات** | Saheeh International (وهي في quranenc)، وDiyanet للتركية، وكولييف للروسية |
| **الشفافية** | سطرُ إفصاحٍ عن الذكاء الاصطناعي في كلّ صفحةٍ منشورة، لا تحذفه الجهة |
| **الخصوصية** | سياسةٌ معلنة على `/privacy` في المنصّة |

**حالتا الاختبار في الوثيقة:**
- **آيةٌ منقولة بخطأ:** كلمةٌ مبدّلة، أو آيةٌ مركّبة من سورتين، لا تُطابَق فلا تُنشر. أمّا سقطُ كلماتٍ من الحفظ بلا تبديل فيُطابَق، وتُنشر الآية بلفظ المصحف كاملاً.
- **«أعطني حديثاً» ← رفض الاختلاق:** المنصّة لا تولّد حديثاً من عندها. وما يُنسب إلى النبيّ ﷺ ولا أصل له في الكتب يُحذف، ولا يُقرَّب إلى أقرب حديث.

## أداة «تحقّق» — مطابقة الآيات والأحاديث في أيّ نصّ

على `/verify`، بلا حساب. يلصق الباحث مقالاً أو خطبةً أو رسالةً متداولة، فيرى كلّ آيةٍ وحديثٍ فيها بحكمه وسببه وموضعه.

| الطبقة | كيف |
|---|---|
| **الاستخراج** | المرحلة الثالثة من [`prompts/islamic/PROMPT-PACK.md`](prompts/islamic/PROMPT-PACK.md) بتعليماتها كما هي: يُنقل لفظ الشاهد حرفاً بحرف، بلا تصحيح |
| **المطابقة** | المحقّقان الحتميّان نفساهما (`QuranVerifier` و`HadithVerifier`)، **بلا نموذج لغوي** |
| **التقرير** | لكلّ شاهد حكمٌ من أربعة، وسببُه بعبارةٍ ثابتة يختارها الخادم، ولفظُ المصدر وموضعُه ودرجتُه كما نصّ عليها المصدر |

**الأحكام الأربعة:**

| `verdict` | معناه |
|---|---|
| `exact` | طابق لفظ المصدر بعد توحيد الرسم والتشكيل |
| `partial` | قريبٌ من لفظ حديثٍ في المصدر وليس مطابقاً، ويُعرض لفظ المصدر للمقارنة وحدها |
| `none` | لم يُعثر عليه في المصحف أو في الكتب السبعة. **وليس هذا حكماً بوضعه** |
| `unverifiable` | نوعٌ لا مصدر مرجعيّ له عندنا، كأقوال العلماء |

**الحدود:** خمسة طلبات في الساعة لكلّ عنوان، و4000 حرف للنصّ (`VERIFY_PER_HOUR` و`VERIFY_MAX_CHARS`). وسقف الإنفاق العامّ يُفحص قبل كلّ نداء، ونداءات الأداة تُحسب فيه. **ويُحذف النصّ وتقريره بعد سبعة أيام**، ويبقى من الطلب كلفته وعدد شواهده.

### الواجهة البرمجية

غير متزامنة: `POST` يُعيد معرّف الطلب فوراً، و`GET` يُعيد حاله ثمّ تقريره. والحقول هي حقول الصفحة نفسها.

```bash
curl -X POST https://<host>/api/v1/verify \
  -H 'Content-Type: application/json' \
  -d '{"text": "قال رسول الله ﷺ: «أحب الأعمال إلى الله أدومها وإن قل»"}'
# 202 Accepted — Location: /api/v1/verify/{id}

curl https://<host>/api/v1/verify/{id}
```

```jsonc
{
  "check": {
    "id": "01a1…",
    "status": "done",              // queued | extracting | verifying | done | failed
    "counts": { "exact": 0, "partial": 1, "none": 0, "unverifiable": 0 },
    "findings": [{
      "index": 1,
      "kind": "hadith",            // ayah | hadith | athar | scholar_quote
      "quoted": "أحب الأعمال إلى الله أدومها وإن قل",
      "verdict": "partial",
      "reason": { "code": "hadith_partial", "text": "قريبٌ من لفظ الحديث في المصدر (رواه مسلم، رقم ١٨٣٠) …" },
      "notes": [],
      "source": {
        "text": "…النصّ كاملاً بسنده…",
        "matn": "أَحَبُّ الأَعْمَالِ إِلَى اللَّهِ تَعَالَى أَدْوَمُهَا وَإِنْ قَلَّ",
        "reference": "رواه مسلم، رقم ١٨٣٠",
        "grade": { "value": "sahih", "label": "صحيح", "stated": true },
        "similarity": 86
      }
    }],
    "error": null,
    "expires_at": "2026-10-11T09:00:00+03:00"
  }

```

| الرمز | متى |
|---|---|
| `202` | قُبل الطلب ووُضع في الطابور |
| `422` | النصّ فارغ أو أقصر من 20 حرفاً أو أطول من 4000 |
| `429` | تجاوز حدّ الطلبات، ومعه `Retry-After` بالثواني |
| `503` | الإنفاق موقوف مؤقّتاً |
| `410` | انقضت مدّة التقرير وحُذف |

## التشغيل محلّياً

المتطلّبات: PHP 8.3 وPostgreSQL 16 وNode 20 (وRedis إن أردت Horizon).

وأدواتٌ على الخادم نفسه، ومساراتها في `.env`:

- **ffmpeg** (وفيه ffprobe): لا غنى عنه لرفع ملفّ الصوت أو الفيديو وللتفريغ الصوتي. بدونه يُردّ كلُّ ملفٍّ يُرفع.
- **yt-dlp**: لروابط يوتيوب. وبدونه يبقى الرفع واللصق اليدوي.
- **Chrome أو Chromium**، اختياريّ (`SHARE_CARD_CAPTURER=chrome`): لصورة مشاركةٍ لكلّ خلاصة ولقياس فيض الشرائح. وبدونه تأخذ الخلاصاتُ بطاقةَ المنصّة.

و`php artisan khulasah:preflight` يقول ما ينقص منها.

```bash
cp .env.example .env && composer install && npm install
php artisan key:generate && php artisan migrate
php artisan db:seed                                    # إعداد النماذج وحده
php artisan khulasah:seed-hadith
php artisan serve                                      # http://localhost:8000
npm run dev                                            # Vite (في طرفية ثانية)
php artisan queue:work                                 # أو php artisan horizon مع Redis
```


**لا حساب جاهزاً.** يُنشأ مشرف المنصّة بأمر واحد، ثمّ يُنشئ الجهات ويدعو فِرَقها من لوحته:

```bash
php artisan tinker --execute="app(App\Support\TenantContext::class)->withoutScope(fn () => App\Models\User::forceCreate(['tenant_id' => null, 'name' => 'مشرف المنصّة', 'email' => 'you@example.com', 'password' => Illuminate\Support\Facades\Hash::make('كلمة-مرور-قويّة'), 'role' => App\Enums\Role::Owner, 'email_verified_at' => now()]));"
```

**النماذج.** قيمة `MODEL_GATEWAY` الافتراضية `fake`، والبوّابة الوهمية تقرأ ردوداً مسجّلة من `tests/Fixtures/model-responses/`. **ولا ردود مسجّلة في المستودع**، فتُسجَّل عند الحاجة بـ`php artisan khulasah:record-response`، وهو ينادي نموذجاً حقيقياً مرّةً لكلّ مرحلة. أو تُستعمل النماذج الحقيقية مباشرةً. والتشغيل الحقيقي يحتاج `MODEL_GATEWAY=real` ومفاتيح المزوّدين في `.env`، ثمّ `php artisan khulasah:preflight` ليبيّن ما ينقص قبل أيّ إنفاق.

**المصحف** يُجلب من واجهة Quran Foundation بحساب مطوّر مجّاني: `QURAN_CLIENT_ID` و`QURAN_CLIENT_SECRET` في `.env`، ثمّ `php artisan khulasah:seed-quran`. أمّا الاختبارات فلا تحتاجه، لأنّها تبذر عيّنة من `tests/Fixtures/quran/`.

## الاختبارات

```bash
npm ci && npm run build
php artisan test                            # 1691 اختباراً
php artisan test --filter=EvidenceFixtures  # الشواهد المدسوسة وحدها
./vendor/bin/pint --test                    # تنسيق PHP
npx tsc --noEmit                            # فحص الأنواع
```

**تعمل الاختبارات على Postgres لا على sqlite**، لأنّ المنصّة تعتمد أعمدة `jsonb` وفهارس نصّية عربية يختلف سلوكها بين المحرّكين.
