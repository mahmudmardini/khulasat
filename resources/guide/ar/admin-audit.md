# سجلّ التدقيق {#admin-audit}

**كلّ فعلٍ يغيّر شيئاً في لوحة المشرف يُقيَّد**: من فعله، ومتى، وما تغيّر (من ← إلى)، وسببه المكتوب. فتعرف بعد أشهر لماذا رُفعت حدود جهة، أو مَن بدّل نموذجاً، أو مَن دخل بهوية جهةٍ وكم بقي.

تراه في موضعين:

- **الرئيسية ← آخر ما جرى**: آخر الأفعال على المنصّة كلّها.
- **صفحة الجهة**: ما يخصّ تلك الجهة وحدها.

## ما يُقيَّد {#admin-audit-actions}

| الفعل | مثال |
|---|---|
| إنشاء جهة | جهةٌ جديدة ومالكها. |
| تعديل حدود جهة / تطبيق باقة | مع مرجع التحويل في السبب. |
| تعديل حالة اشتراك | إيقافٌ أو إعادة تفعيل. |
| تبديل وضع الشواهد | مع سببه. |
| تعليمات قوالب الكاروسيل وتوليدها | لجهةٍ بعينها. |
| تعديل إعداد نموذج | المرحلة، وما تغيّر. |
| دخولٌ بهوية جهة / خروجٌ منها | ومدّة الجلسة. |
| إعادة مهمّة / إلغاء مهمّة | — |
| حسم اعتراض | إزالة الصفحة، أو المعالجة، أو الردّ. |
| معالجة طلبٍ وارد | — |
| إيقاف الطابور / رفع الوقف | مع سببه. |

> [!LIMIT]
> السجلّ **للقراءة فقط**. لا يُعدَّل ولا يُحذف منه شيء، ولا يُصدَّر من اللوحة.
