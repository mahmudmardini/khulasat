# معاني الكلمات {#glossary}

كلماتٌ تتكرّر في خُلاصات، ومعنى كلٍّ منها بلغةٍ بسيطة.

| الكلمة | معناها |
|---|---|
| **الجهة** | المسجد أو المركز أو المؤسّسة التي تستعمل خُلاصات لتلخيص دروسها. ولكلّ جهةٍ لوحتها وفريقها وهويّتها. |
| **مالك الجهة** | المسؤول عن حساب الجهة، ويملك كلّ شيءٍ داخلها. |
| **المحرّر** | عضوٌ في فريق الجهة ينشئ الملخّصات ويراجعها وينشرها. |
| **المطّلع** | عضوٌ يرى الملخّصات فقط. |
| **مشرف المنصّة** | من يدير خُلاصات كلّها: الجهات، وحدودها، والنماذج، والاعتراضات. |
| **الملخّص** | الصفحة المكتوبة التي يُخرجها النظام من الدرس. |
| **المصدر** | ما يُعطى للنظام: رابط يوتيوب، أو ملفّ صوت أو فيديو، أو نصّ الدرس. |
| **التفريغ** | تحويل كلام الدرس المسموع إلى نصٍّ مكتوب. |
| **المحور** | فكرةٌ رئيسة من أفكار الدرس، ولها عنوانها في الصفحة. |
| **الشاهد** | آيةٌ أو حديثٌ أو أثرٌ ذكره الملقي في الدرس. |
| **التخريج** | ذكر الموضع الذي ورد فيه الحديث في كتب الحديث، مثل «رواه الترمذي، رقم ٢٦٤٦». |
| **الدرجة** | حكم الحديث كما نصّ عليه المصدر: صحيح، أو حسن، أو ضعيف، أو موضوع. |
| **المطابقة** | مقارنة لفظ الشاهد بلفظه في المصدر حرفاً بحرف. |
| **المراجعة** | قرارك في شاهدٍ لم يطابق مصدره تماماً قبل النشر. |
| **النشر** | جعل صفحة الملخّص متاحةً على الإنترنت برابطها. |
| **لغات النشر** | اللغات التي تُنشر بها صفحة الملخّص للقرّاء. |
| **لغة اللوحة** | لغة الأزرار والقوائم التي تراها أنت. |
| **القالب** | الشكل العامّ لصفحة الملخّص. |
| **لوحة الألوان** | مجموعة الألوان التي تُرسم بها صفحات جهتك. |
| **الكاروسيل / الشرائح** | سلسلة صورٍ متتالية للنشر على إنستغرام. |
| **الحصّة** | عدد الملخّصات المسموح بها لجهتك في الشهر. |
| **إعادة التوليد** | إعادة إنشاء الملخّص من مصدره بصياغةٍ جديدة. |
| **الباقة** | مستوى اشتراك الجهة، ويحدّد حدودها وما يتاح لها. |
::: admin
| **الانتحال (الدخول بهوية الجهة)** | أن يرى المشرف لوحة جهةٍ كما يراها مالكها، للدعم الفنّي. |
| **سقف الإنفاق** | أقصى ما تصرفه المنصّة على نماذج الذكاء الاصطناعي في اليوم والشهر. |
| **النموذج** | نظام الذكاء الاصطناعي الذي ينفّذ مرحلةً من مراحل الإعداد. |
| **المهمّة** | ملخّصٌ واحد بكلّ مراحل إعداده، كما يراه المشرف. |
| **الطابور** | قائمة الأعمال التي تنتظر دورها على الخادم. |
:::
