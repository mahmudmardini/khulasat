# The audit log {#admin-audit}

**Every action that changes something in the administrator panel is recorded**: who did it, when, what changed (from → to), and the written reason. So months later you know why an institution's limits were raised, who switched a model, or who signed in as an institution and for how long.

You see it in two places:

- **Home → «آخر ما جرى»** (recent activity): the latest actions across the whole platform.
- **The institution page**: what concerns that institution alone.

## What is recorded {#admin-audit-actions}

| Action | Example |
|---|---|
| Creating an institution | A new institution and its owner. |
| Changing an institution's limits / applying a plan | With the transfer reference in the reason. |
| Changing a subscription's status | Pausing or reactivating. |
| Switching the evidence mode | With its reason. |
| Carousel template instructions and generation | For a particular institution. |
| Changing a model setting | The stage, and what changed. |
| Signing in as an institution / leaving it | And how long the session lasted. |
| Restarting a job / cancelling a job | — |
| Settling a complaint | Removing the page, handling it, or dismissing it. |
| Handling an incoming request | — |
| Halting the queue / lifting the halt | With its reason. |

> [!LIMIT]
> The log is **read-only**. Nothing in it is edited or deleted, and it is not exported from the panel.
