# Incoming requests {#admin-invites}

Khulasat's public landing page has a form visitors use to get in touch. What they send arrives in **الطلبات الواردة** (incoming requests). Because accounts are by invitation, **every new account starts here**.

![Incoming requests.](shot:admin-invites)

## The two kinds of request {#admin-invites-kinds}

- **رسالة** (message): a question or enquiry, with the name, how to reach them and the message.
- **تجربة بمحاضرة** (a trial with a lecture): an institution that wants to try the platform on a specific lecture, with the name, role, how to reach them, **the lecture link** and an optional message.

## Handling a request {#admin-invites-handle}

1. Contact the sender using the details they wrote.
2. If it is an institution that wants to subscribe, [create an institution for it](#admin-tenants-create).
3. Click **علّمه معالَجاً** (mark as handled). If you need it again, **أعده إلى الانتظار** (return it to waiting).

At the top of the page is the number waiting for an answer, and two buttons: **المنتظِرة وحدها** (waiting only) and **الكلّ** (all).

> [!LIMIT]
> The system does not reply to requests and does not create an account from a request automatically. You get in touch and create the institution.
