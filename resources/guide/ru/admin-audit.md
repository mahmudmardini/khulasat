# Журнал аудита {#admin-audit}

**Каждое действие, которое что-то меняет в панели администратора, записывается**: кто, когда, что изменилось (было → стало) и записанная причина. Так и через месяцы известно, почему подняли лимиты организации, кто сменил модель или кто входил от имени организации и как долго.

Он виден в двух местах:

- **Главная → «آخر ما جرى»** (последние события): последние действия на всей платформе.
- **Страница организации**: то, что касается только её.

## Что записывается {#admin-audit-actions}

| Действие | Пример |
|---|---|
| Создание организации | Новая организация и её владелец. |
| Изменение лимитов организации / применение тарифа | С номером перевода в причине. |
| Изменение статуса подписки | Приостановка или повторная активация. |
| Смена режима доводов | С причиной. |
| Инструкции и создание шаблонов карусели | Для конкретной организации. |
| Изменение настройки модели | Этап и что изменилось. |
| Вход от имени организации / выход | И длительность сеанса. |
| Перезапуск задания / отмена задания | — |
| Решение по жалобе | Снятие страницы, решение без снятия или отклонение. |
| Обработка входящей заявки | — |
| Остановка очереди / снятие остановки | С причиной. |

> [!LIMIT]
> Журнал **только для чтения**. В нём ничего не правится и не удаляется, и из панели он не выгружается.
