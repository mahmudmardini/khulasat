# Модели {#admin-models}

Каждый этап подготовки выполняет **модель ИИ**, которую выбираете вы. В разделе **النماذج** (модели) — по карточке на каждый этап.

![Модели: карточка для каждого этапа и кнопка «تعديل» (изменить).](shot:admin-models)

> [!WARNING]
> **Смена модели меняет и качество продукта, и его стоимость**, и действует **сразу** для каждого резюме, которое начнётся после этого, — без выкладки и перезапуска. Каждое изменение записывается на ваше имя.

## Этапы {#admin-models-stages}

| Этап | Что делает |
|---|---|
| `cleaning` | Очищает текст лекции. |
| `extracting_structure` | Выделяет главную мысль и разделы. |
| `extracting_evidence` | Находит аяты и хадисы в тексте (им пользуется и Инструмент проверки). |
| `writing` | Пишет текст резюме. |
| `output_metadata` | Заголовок, описание и ссылка страницы. |
| `translating` | Переводит резюме на языки публикации. |
| `carousel` | Тексты слайдов для Instagram. |
| `carousel_design` | Предлагает организациям шаблоны карусели. |
| `quiz` | Вопросы теста на понимание. |
| `lecture_details` | Считывает сведения о собрании с афиши лекции (пока не подключено к экрану). |

## Поля карточки {#admin-models-fields}

- **المزوّد** и **النموذج** (поставщик и модель): компания и название модели.
- **المزوّد البديل** и **النموذج البديل** (резервные поставщик и модель): используются, если основной не сработал.
- **أقصى مخرَج** (максимальный вывод), **مستوى التفكير** (уровень рассуждения), **المهلة** (таймаут, секунды), **المحاولات** (попытки) и **عند الاستنفاد** (что делать, если все попытки неудачны).
- **سعر المدخل / مليون** и **سعر المخرَج / مليون** (цена ввода и вывода за миллион токенов): цены поставщика, по которым везде считаются расходы. **Обновляйте их, когда поставщик меняет цены**, иначе цифры расходов будут неверны.
- **فعّال** (активна).

Нажмите **تعديل** (изменить), внесите изменение, при желании укажите **سبب التغيير** (причина изменения), если это эксперимент, и сохраните.

> [!LIMIT]
> - **Ключей поставщиков здесь нет.** Они задаются только в настройках сервера и в панели никогда не показываются.
> - **Проверка аятов и хадисов обходится без модели**, поэтому карточки у неё нет. Это фиксированная текстовая сверка.
