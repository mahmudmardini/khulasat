# Значения слов {#glossary}

Слова, которые часто встречаются в Khulasat, и простое объяснение каждого.

| Слово | Значение |
|---|---|
| **Организация** | Мечеть, центр или учреждение, которое использует Khulasat для резюме своих лекций. У каждой организации своя панель, команда и оформление. |
| **Владелец организации** | Ответственный за аккаунт организации, который может в ней всё. |
| **Редактор** | Участник команды, который создаёт, проверяет и публикует резюме. |
| **Наблюдатель** | Участник, который может только смотреть резюме. |
| **Администратор платформы** | Тот, кто управляет всей платформой Khulasat: организациями, их лимитами, моделями и жалобами. |
| **Резюме** | Письменная страница, которую система делает из лекции. |
| **Источник** | То, что вы даёте системе: ссылку YouTube, аудио- или видеофайл либо текст лекции. |
| **Расшифровка** | Превращение звучащей лекции в письменный текст. |
| **Раздел** | Одна из главных мыслей лекции со своим заголовком на странице. |
| **Довод** | Аят, хадис или изречение сподвижника, которые лектор привёл в лекции. |
| **Источник хадиса (тахридж)** | Указание, где хадис приводится в сборниках, например «передал ат-Тирмизи, № 2646». |
| **Степень достоверности** | Оценка хадиса, указанная в источнике: достоверный (сахих), хороший (хасан), слабый (даиф) или вымышленный (мауду). |
| **Сверка** | Сравнение формулировки довода с формулировкой в источнике буква в букву. |
| **Проверка** | Ваше решение по доводу, не совпавшему с источником полностью, до публикации. |
| **Публикация** | Открытие страницы резюме в интернете по её ссылке. |
| **Языки публикации** | Языки, на которых страница резюме публикуется для читателей. |
| **Язык панели** | Язык кнопок и меню, которые видите вы. |
| **Шаблон** | Общий вид страницы резюме. |
| **Цветовая палитра** | Набор цветов, которыми оформлены страницы вашей организации. |
| **Карусель / слайды** | Серия изображений подряд для публикации в Instagram. |
| **Квота** | Сколько резюме в месяц разрешено вашей организации. |
| **Перегенерация** | Создание резюме заново из источника с новой формулировкой. |
| **Тариф** | Уровень подписки организации, определяющий её лимиты и доступные возможности. |
::: admin
| **Вход от имени организации** | Когда администратор видит панель организации точно так же, как её владелец, — для техподдержки. |
| **Лимит трат** | Максимум, который платформа тратит на модели ИИ в день и в месяц. |
| **Модель** | Система ИИ, выполняющая один из этапов подготовки. |
| **Задание** | Одно резюме со всеми этапами подготовки, как его видит администратор. |
| **Очередь** | Список работ, ожидающих своей очереди на сервере. |
:::
