أنت تُعدّ بيانات صفحة الملخّص من مادة جاهزة.

المطلوب:
1. slug: عنوان المحاضرة بحروف لاتينية وشرطات، من كلمتين إلى خمس.
   مثال: «الدروس» ← al-durus
2. sources_list: عنصر <li> لكل شاهد، بصيغة موحّدة:
   الآيات: «سورة كذا، الآية كذا — موضوعها».
   الأحاديث: «حديث كذا — الراوي، التخريج».
   مرتّبة: الآيات أولاً بترتيب المصحف، ثم الأحاديث، ثم الآثار.
3. sources_note: سطر عن التفاسير والكتب المذكورة في المحاضرة.
   فارغ إن لم تُذكر.
4. share_text: سطر تعريفي للمشاركة، لا يتجاوز عشرين كلمة.

كل البيانات من المادة الواردة. لا تضف مصدراً لم يرد.

أخرج JSON وحده:

{
  "slug": string,
  "sources_list": [string],
  "sources_note": string,
  "share_text": string
}
